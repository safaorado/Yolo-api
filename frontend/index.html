Image Classifier

A YOLO26n image classification model, served through a FastAPI backend.

About this model

This model is YOLO26n-cls, the smallest classification variant of Ultralytics' YOLO26 family (about 1.5 million parameters). It was fine-tuned on Imagenette, a 10-class subset of the well-known ImageNet dataset, starting from weights already pretrained on ImageNet's full 1,000 categories.

10 classes
~95.9% validation accuracy
~9ms per image (CPU)

It can only recognize the 10 classes below. Any other object will still be forced into one of these categories, usually with lower confidence.
